# public-sheet-demo

이 저장소는 공개 정적 페이지를 위한 예시 사이트입니다.

## 내용
- `index.html`: 메인 인증 완료 페이지
- `styles.css`: 페이지 스타일

## 공개 방법
GitHub 저장소에서 Settings > Pages로 이동해,
"Deploy from a branch"를 선택하고 `main` 브랜치의 루트를 게시하면 됩니다.

## 공개 URL 예시
https://yeonhob51-tech.github.io/public-sheet-demo/

## 현재 페이지
인증 완료 페이지는 다음 메시지를 표시합니다:

`인증이 완료되었습니다!`
